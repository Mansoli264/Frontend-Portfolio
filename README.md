# Personal Portfolio Website

Hi! I'm Manali, an aspiring Frontend Developer who enjoys learning how websites are built and turning ideas into clean, user-friendly experiences.

This repository contains the source code for my personal portfolio website. I built it as part of my journey into frontend development, using the fundamentals of HTML and CSS.

## About the Project

The goal of this project is to create a personal space where I can introduce myself, showcase the technologies I'm learning, share my projects, and make it easy for people to connect with me.

I'm building this portfolio step by step while improving my frontend development skills.

## Built With

- **HTML5** – For page structure and semantic elements.
- **CSS3** – For styling, layouts, and visual design.
- **Flexbox & CSS Grid** – For arranging page content.
- **Media Queries** – For responsive layouts across different screen sizes.

## What's Inside

- A navigation bar to move between sections.
- An introduction and About Me section.
- A section highlighting my current technical skills.
- Project cards to showcase my work.
- A contact form interface.
- A responsive layout for desktop, tablet, and mobile.
